# Список и карточка объявления

## Список объявлений

```http
GET /api/ads
```

Ручка публичная. Она нужна для ленты объявлений и возвращает только легкие данные для карточек на экране списка.

Ответ:

```json
{
  "total_count": 87,
  "items": [
    {
      "id": "0a0b62e8-d9ce-4a7b-821b-dab4afca9f97",
      "image_urls": [
        "https://example.com/image.jpg"
      ],
      "price": "45 000",
      "rooms_count": "2",
      "area": "54.5",
      "floor": 7,
      "total_floor": 16,
      "address": "Омск, улица Ленина, 10"
    }
  ]
}
```

`total_count` считается по тем же фильтрам, что и список. `limit` и `offset` влияют только на `items`.

## Подробная карточка

```http
GET /api/ads/{id}
```

Ручка публичная. `id` нужно брать из `GET /api/ads`.

Эта ручка возвращает полный объект объявления: описание, `address_details`, характеристики, владельца, просмотры, условия аренды и остальные поля, которые раньше приходили прямо в списке.
